香橙派开发总结

一、环境配置​

1.烧录镜像​

第一步，先找资料，找到的资料如下 Orange Pi - Orange Pi 论坛、 Orange Pi AIpro_昇腾论坛 (hiascend.com) Orange Pi - Orangepi官方资料

然后，烧录镜像到TF卡中，注意：拨码开关BOOT1和2处于右设备状态，对应启动设备是TF卡；使用官方资料提供的Linux镜像烧录工具-balenEther进行，烧录、校验镜像各12min(不同读卡器速度不同)；可能会出现一个问题：校验失败导致最后烧录失败，不过我这边试了之后不影响，sd卡插上香橙派仍然可以使用。

镜像烧录完成之后，插入香橙派然后电源type-c插上启动就可以，外接示屏、键盘、鼠标（使用三模键盘，可实现个人PC和香橙派自由切换😁）

2.登录香橙派Linux系统​

  1. 如果开发板连接了网线，可以通过 ssh 远程登录 Linux 系统。
  2. 如果开发板连接好了调试串口，可以使用串口终端登录Linux 系统。
  3. 如果连接了开发板到 HDMI 显示器，可以通过 HDMI 显示的终端登录到Linux 系统。

3.配置网络​

3.1 以太网口​

先将网线的一端插入开发板的以太网接口，网线的另一端接入交换机或者路由器 系统启动后会通过 DHCP 自动给以太网口分配 IP 地址。

# 查看 IP 地址
ip a s eth0%% %% %% %%  %% %% %% %%

3.2 通过 nmcli 命令连接 WIFI 的方法​

# 1.扫描周围的 WIFI 热点
nmcli dev wifi
# 2.使用 nmcli 命令连接扫描到的 WIFI 热点
sudo nmcli dev wifi connect wifi_name password wifi_passwd
# 3.查看 wifi 的 IP 地址
ip addr show wlan0
# 4.测试网络的连通性
ping www.orangepi.org -I wlan0

3.3 通过 nmtui 图形化方式连接 WIFI 的方法​

# 打开 wifi 连接的界面
sudo nmtui
# 选择 Activate a connect 后回车，就能看到所有搜索到的 WIFI 热点
# 选择想要连接的 WIFI 热点后再使用 Tab 键将光标定位到Activate 后回车
# 然后会弹出输入密码的对话框，在 Pssword 内输入对应的密码然后回车就会开始连接 WIFI。
# 查看ip地址
ip a s wlan0

3.4 使用 nmcli 命令来设置静态 IP 地址​

# 以查看网络设备的名字
nmcli con show

# 设置静态IP地址
# a. "Wired connection 1" 表示设置以太网口的静态IP 地址，如果需要设置    WIFI 的静态 IP 地址，请修改为 WIFI 网络接口对应的名字（通过nmcli con show 命令可以获取到）。 
# b. ipv4.addresses 后面是要设置的静态 IP 地址，可以修改为自己想要设置的值。
# c. ipv4.gateway 表示网关的地址。
sudo nmcli con mod "Wired connection1"\ ipv4.addresses "192.168.1.110" \ ipv4.gateway "192.168.1.1" \ ipv4.dns "8.8.8.8" \ ipv4.method "manual"

# 重启linux系统
sudo reboot
# 查看IP 地址是否已经设置为想要的值了
ip addr show eth0

二、开发板使用​

1.板载 LED 灯​

开发板上有两个绿色的 LED 灯

  1. 靠近关机按键的绿灯：此绿灯为电源指示灯，由硬件控制其亮灭，软件无法控制。只要开发板接入了 Type-C 电源并上电了，此绿灯就会点亮。
  2. MIPI LCD 和 CAMERA0 之间的绿灯：此绿灯由 GPIO4_19 控制其亮灭，可以作为 SATA 硬盘的指示灯或者其他需要的用途。目前发布的Linux 系统默认在DTS中将其点亮。当看到此灯点亮后，至少可以说明 Linux 内核已经启动了。

2.HDMI 接口使用​

开发板有两个 HDMI2.0 接口，目前只有 HDMI0 支持显示Linux 系统的桌面

官方手册中描述：当 Linux 系统的桌面系统关闭时，HDMI0 和 HDMI1 还可以用于NVR二次开发场景输出图片。

理解：即使Linux系统的桌面环境被关闭或者没有运行，HDMI0和HDMI1这两个接口仍然可以被用来输出图像。

官方手册：关闭 drm 的配置，打开vdp 的配置 关键词解释： DRM：Direct Rendering Manager的缩写，它是Linux内核中的一个子系统，用于提供一个用户空间API，使得用户空间程序可以直接访问图形硬件。这对于运行图形密集型应用（如游戏或视频播放器）非常重要，因为它们需要直接访问和控制图形硬件以获得最佳性能。DRM也提供了一种方式，使得多个应用程序可以共享图形硬件，而不会相互干扰。

2.1 HDMI0显示图片​

# 切换到 root 用户
sudo -i
# 进入 HDMI0 测试程序所在路径
cd /opt/opi_test/hdmi0_pic
# 运行 update_dt.sh 脚本更新下 dt.img（关闭 drm 的配置，打开vdp 的配置）。update_dt.sh 脚本运行完后会自动重启 Linux 系统。
./update_dt.sh
# 重启后再次进入 HDMI0 测试程序所在的路径，然后运行test.sh 脚本就会播放一张图片到 HDMI 显示器（默认显示 10 秒），并且同时会播放一段音频到HDMI 显示器，如果 HDMI 显示器支持播放音频的话，还能听到声音
./test.sh
