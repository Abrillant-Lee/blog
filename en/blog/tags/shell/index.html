华为云HECS服务器开发总结

1.新建用户​

创建一个普通用户用于日常操作，只有在需要执行特定的管理员任务时，才使用root用户或者sudo命令。这样可以提高系统的安全性，同时也可以防止因为误操作导致的问题。

新建用户，并添加主目录

useradd name -m

添加用户密码

passwd name

2.配置免密登录​

每次使用ip连接服务器比较麻烦，容易忘记，在windows下创建配置文件~/.ssh/config,文件中输入一下内容，就可以通过ssh myserver1连接服务器

Host myserver1
   HostName IP地址或域名
   User 用户名

Host myserver2
   HostName IP地址或域名
   User 用户名

使用别名登陆后还需要输入密码，密码输错/忘记等等会造成一定开发时间浪费 windows下创建密钥：然后一直回车即可，执行结束后，~/.ssh/目录下会多两个文件： id_rsa：私钥 id_rsa.pub：公钥

ssh-keygen

Linux中公钥中的内容，复制到myserver中的~/.ssh/authorized_keys文件里即可,没有的话直接创建即可。

配置不熄屏幕​

  1. 安装 dconf-cli 工具： 
    sudo apt install dconf-cli
  2. 通过以下命令将屏幕闲置关闭时间设置为0（即从不关闭）：
gsettings set org.gnome.desktop.session idle-delay 0
  1. 禁用屏幕保护程序锁定：
gsettings set org.gnome.desktop.screensaver lock-enabled false
gsettings set org.gnome.desktop.screensaver idle-activation-enabled false
gsettings set org.gnome.desktop.screensaver lock-delay 0
gsettings set org.gnome.desktop.screensaver ubuntu-lock-on-suspend false

Powershell​

环境变量​

1.设置环境变量​

  1. 临时生效（仅限当前会话）
$env:变量名 = "变量值"
  1. 永久生效（对用户生效）
[Environment]::SetEnvironmentVariable("MY_VARIABLE", "SomeValue", "User")

这条命令不会立即影响到当前会话，你需要关闭并重新打开PowerShell窗口才能看到变化。

  1. 使用 setx 命令（适用于旧版Windows或简单场景）

    虽然 setx 不是PowerShell专用的命令，但它也可以用来设置永久环境变量，对当前会话无效，但在新启动的命令提示符或PowerShell会话中生效：

    setx MY_VARIABLE "SomeValue" /M

    这里的 /M 参数表示设置系统级别的环境变量。使用 setx 后，你需要关闭并重新打开命令行界面才能看到变量。

2.删除环境变量​

  1. 对于当前会话： 如果你想从当前PowerShell会话中移除一个环境变量，可以使用 Remove-Item cmdlet，指定环境变量的名称。注意，这仅影响当前会话，不会改变注册表中的设置，因此重启PowerShell后变量会恢复。
Remove-Item -Path "Env:\VariableName"
  1. 永久删除（用户级别）：
[Environment]::SetEnvironmentVariable("VariableName", "", "User")

【开发说明】​

实现的系统面向至少2类行业企业的碳核算模型以及碳交易应用场景，构建碳排放数据的追踪、核查、确权系统，关键功能要充分考虑目标场景的限制和特点，程序应便于部署和实用。

系统关键模块设计：采用前后端分离的方式，企业碳核算以及交易、第三方监管等服务功能，设计实现组件化服务，通过提供专门的API接口，供前端交互时调用，便于前后端交互。

【技术要求与指标】​

（1）开发程序包括且不限于小程序、Web网站、HTML5等，可运行在常规算力设备上（如：i3 x86处理器，8G内存，40G磁盘）。

（2）区块链底层选用以太坊、超级账本Hyperledger等基于开源的或第三方商业区块链开发平台，关系数据库采用MySQL或其他数据库。

（3）选用加密技术（加密算法、哈希函数和数字签名等）对企业数据进行加密，确保区块链中数据的安全和隐私。

（4）区块链节点数不少于3个，合理设计区块大小，使得每轮上链存证确认完成的时间尽可能短。

（5）界面设计美观，具有一定的可操作性，用户使用方便，鲁棒性强，没有功能错误。

节能管家使用区块链做什么

1. 碳排放数据存证：​

  • 利用区块链技术进行办公空间(配置节能管家系统)碳排放与碳减排数据的上传和存证。

    • 办公空间内所有与碳排放相关的数据，如能源消耗、减排措施的效果等，都将被记录在区块链上。区块链的不可篡改性和透明性特点使得这些数据更加可靠，为办公空间提供了一个可信的碳排放记录系统。

    • 防止企业作弊，保证碳排放数据的真实性和可信度。

2. 碳排放趋势分析​

  • 区块链技术可以帮助记录和分析园区内碳排放的历史趋势和模式，这对于预测未来的碳排放走向和制定长期的减排规划至关重要。

3. 智能合约自动执行交易：​

  • 设计并部署智能合约来自动执行碳信用的买卖交易，减少人工干预，降低交易成本和时间，提高交易效率。

开发相关概念​

区块：在区块链技术中，区块是数据的基本单位。每个区块都包含一组交易记录，并且链接到前一个区块，形成一个链式结构。每个区块还包含一个时间戳和一个难题的解，这个难题的解是通过计算（也称为“挖矿”）得到的。

区块链：区块链是由多个区块按照时间顺序链接而成的链式数据结构。每个区块都包含前一个区块的哈希值，这样就形成了一个每个区块都指向前一个区块的链式结构。这种结构使得一旦数据被写入区块链，就不能被修改或删除，保证了数据的不可篡改性。

区块链节点：区块链节点是构成区块链网络的基本单位，它是一个运行着区块链协议的服务器或计算机。每个节点都保有区块链的完整副本，可以验证和转发交易，以及创建新的区块。

区块链网络：区块链网络是由多个区块链节点组成的分布式网络。在这个网络中，每个节点都保有区块链的完整副本，并遵循同一套协议来验证和记录交易。这种去中心化的网络结构提供了高度的透明度和安全性。
