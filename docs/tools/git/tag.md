# Git Tag 命令指南

`git tag` 命令用于在 Git 历史记录中创建标签。标签通常用于标记重要的点（如发布版本）。Git 支持两种类型的标签：轻量标签和附注标签。以下是如何使用 `git tag` 的一些示例。

## 1. 创建标签

### 轻量标签
轻量标签就像一个特定提交的指针，没有额外的元数据。
```sh
git tag v1.0.0
```

### 附注标签
附注标签是一个完整的对象，存储了更多信息，比如标签名称、电子邮件、日期和标签信息。通常用于发布版本。
```sh
git tag -a v1.0.0 -m "Release version 1.0.0"
```
## 2. 查看标签
列出所有标签。

```sh
git tag
```
列出包含特定模式的标签。
```sh
git tag -l "v1.0.*"
``` 
## 3. 删除标签
删除本地标签。

```git tag -d v1.0.0```
删除远程标签。

```sh
git push origin --delete tag v1.0.0
```  

## 4. 推送标签到远程仓库
将单个标签推送到远程仓库。

```
git push origin v1.0.0
```
将所有标签推送到远程仓库。
``` 
git push origin --tags
``` 
## 5. 检查某个标签所指向的提交
显示标签指向的提交。

```sh
git show v1.0.0
```

## 6. 在特定的提交上创建标签
如果需要在某个特定提交上创建标签，可以指定提交的哈希。
```
git tag -a v1.0.0 <commit-hash> -m "Release version 1.0.0"
``` 
## 7. 签名标签
你还可以创建一个带有 GPG 签名的标签。确保你已经配置了 GPG 密钥。

```
git tag -s v1.0.0 -m "Signed release version 1.0.0"
```
这些是 git tag 命令的一些基本用法。标签在版本管理中非常有用，特别是在发布和部署流程中。
